## 中文说明

DSH Desktop `0.1.5` 内置 DeepSeek Harness `{{DSH_VERSION}}`，本版本聚焦运行时同步与上游发布审计的准确性。

### 本版更新

- 内置 DeepSeek Harness 从 `0.1.2-rc.1` 升级到 `{{DSH_VERSION}}`，同步完整 DSH 依赖树与 npm 完整性锁定信息。
- `pnpm-workspace.yaml` 的发布时间例外清单按新的锁文件重建，只保留当前内置版本对应的条目。
- 上游审计改为读取 npm 的 `latest` 与 `next` 标签并取更高者：锁定预发布版本时，不再因为 `latest` 指向更低的版本号而误报发布漂移；锁定版本被同号重新发布或已从 npm 撤回时会明确报错。
- 关于窗口、运行时校验和诊断信息同步显示新的 DSH 版本。
- Node.js 保持 `24.19.0`，pnpm 保持 `11.22.0`；继续校验目标平台 Node、原生模块、SHA-256、依赖供应链和本地 Web 服务启动。

### 安装说明

- Windows x64：下载 `*_x64-setup.exe`，以全机模式安装，系统可能要求管理员权限。
- macOS：Apple Silicon 使用 ARM64 DMG，Intel Mac 使用 x64 DMG。
- Linux x64：可运行 AppImage，或在 Debian/Ubuntu 上安装 deb。
- 现有 DSH Profile、模型配置、插件、缓存和凭据不会被迁移或重写。

### 已知限制

- Windows Authenticode、Apple Developer 签名与公证仍未配置。
- macOS 与 Linux 仍需在对应真实桌面环境完成最终交互验收。
- 内置 DSH 为预发布版本，上游后续 rc 发布需要重新执行锁定、暂存和全平台重建。

## English

DSH Desktop `0.1.5` bundles DeepSeek Harness `{{DSH_VERSION}}` and focuses on runtime synchronization and accurate upstream release auditing.

### What's changed

- Bundled DeepSeek Harness moves from `0.1.2-rc.1` to `{{DSH_VERSION}}`, with the complete DSH dependency tree and npm integrity metadata refreshed.
- The publish-time exclusion list in `pnpm-workspace.yaml` is rebuilt from the new lockfile and keeps only entries for the bundled version.
- The upstream audit now reads the npm `latest` and `next` tags and compares against the higher one: locking a prerelease is no longer reported as release drift when `latest` carries a lower version, while a republished or withdrawn locked version is reported explicitly.
- About, runtime verification, and diagnostic information now report the updated DSH version.
- Node.js stays at `24.19.0` and pnpm at `11.22.0`; target Node binaries, native modules, SHA-256 hashes, supply-chain policy, and local Web service startup remain verified.

### Installation

- Windows x64: download `*_x64-setup.exe`; per-machine installation may require administrator rights.
- macOS: use the ARM64 DMG on Apple Silicon or the x64 DMG on Intel Macs.
- Linux x64: use the AppImage or install the deb package.
- Existing DSH profiles, model settings, plugins, caches, and credentials are not migrated or rewritten.

### Known limitations

- Windows Authenticode and Apple Developer signing/notarization remain unconfigured.
- Final macOS and Linux interaction acceptance still requires real desktop environments.
- The bundled DSH is a prerelease; a later upstream rc requires locking, staging, and rebuilding every platform again.
