## 中文说明

DSH Desktop `0.1.3` 内置 DeepSeek Harness `{{DSH_VERSION}}`，本版本集中完善更新可靠性、操作入口和跨平台一致性。

### 本版更新

- 内置 DeepSeek Harness 从 `0.1.0-rc.7` 升级到 `{{DSH_VERSION}}`，适配显式 Web Profile 参数，并禁止桌面启动时额外打开系统浏览器。
- 更新包改为应用私有目录磁盘缓存，应用重启或网络中断后可以继续下载。
- 增加连接响应超时和 45 秒无进度超时，停滞连接会自动进入最多 5 次的断点续传。
- 标题栏和托盘显示下载百分比、大小、平均速度、预计剩余时间及续传次数。
- 更新内容使用固定尺寸窗口展示，长内容只滚动正文，操作按钮始终可见。
- Windows/Linux 新增 36px 单行标题栏，将应用菜单、更新状态和最小化/最大化/关闭按钮合并展示；浅色与深色配色跟随系统主题，并优化窗口控制图标清晰度；macOS 保持系统原生标题栏。
- 新增自定义“关于 DSH Desktop”窗口，展示构建时间、构建标识、平台架构和内置运行时版本，并可复制公开版本信息。
- 长期驻留托盘时每 24 小时重新检查更新；发布说明由版本文件提供，不再只显示通用安装内容。
- 扩大密码、Cookie、Bearer、Token、Secret 和 `sk-` 等诊断脱敏范围。
- 正式 Release 发布后自动验证公开 `latest.json`、HEAD 文件大小和 HTTP Range 续传能力。
- 启动页使用跨平台文案，不再固定显示 Windows。

### 安装说明

- Windows x64：下载 `*_x64-setup.exe`，以全机模式安装，系统可能要求管理员权限。
- macOS：Apple Silicon 使用 ARM64 DMG，Intel Mac 使用 x64 DMG；当前包仅供内部测试。
- Linux x64：可运行 AppImage，或在 Debian/Ubuntu 上安装 deb。
- 现有 DSH Profile、模型配置、插件、缓存和凭据不会被迁移或重写。

### 已知限制

- Windows Authenticode、Apple Developer 签名与公证仍未配置。
- macOS 与 Linux 仍需在对应真实桌面环境完成最终交互验收。

## English

DSH Desktop `0.1.3` bundles DeepSeek Harness `{{DSH_VERSION}}` and focuses on update reliability, discoverable desktop actions, and cross-platform consistency.

### What's changed

- Bundled DeepSeek Harness moves from `0.1.0-rc.7` to `{{DSH_VERSION}}`, with explicit Web profile arguments and suppression of the upstream external-browser launch inside Desktop.
- Update packages are cached on disk and can resume after network interruption or application restart.
- Response and 45-second no-progress timeouts trigger up to five validated Range resume attempts.
- The title and tray show percentage, transferred size, average speed, ETA, and retry count.
- Release notes use a fixed-size window with a scrollable content region and persistent actions.
- Windows/Linux use a 36px single-row title bar combining native popup menus, update status, and minimize/maximize/close controls. Light and dark palettes follow the system theme, and the window-control glyphs are clearer; macOS keeps its native title bar.
- A custom About DSH Desktop window shows build time, build id, platform architecture, and bundled runtime versions, with a copyable public version summary.
- Long-running tray sessions check once every 24 hours, and version-specific notes feed the updater prompt.
- Diagnostic redaction covers passwords, cookies, bearer values, tokens, secrets, and embedded `sk-` values.
- Published Releases receive a public manifest, HEAD, and HTTP Range smoke test.
- Startup copy is platform-neutral.

### Known limitations

- Windows Authenticode and Apple Developer signing/notarization remain unconfigured.
- Final macOS and Linux interaction acceptance still requires real desktop environments.
