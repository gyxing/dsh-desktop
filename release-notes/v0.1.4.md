## 中文说明

DSH Desktop `0.1.4` 内置 DeepSeek Harness `{{DSH_VERSION}}`，本版本聚焦运行时同步、启动稳定性和 Windows 兼容性。

### 本版更新

- 内置 DeepSeek Harness 从 `0.1.1-rc.2` 升级到 `{{DSH_VERSION}}`，同步完整 DSH 依赖树与 npm 完整性锁定信息。
- 修复 HMR 服务启动失败：在 DSH 入口前显式启用 Node 内部模块访问，Windows 与 POSIX 启动路径保持一致。
- Windows 增加 WebView2 GPU 兼容性配置，改善部分设备的窗口渲染稳定性。
- 关于窗口、运行时校验和诊断信息同步显示新的 DSH 版本。
- 继续校验目标平台 Node、原生模块、SHA-256、依赖供应链和本地 Web 服务启动。

### 安装说明

- Windows x64：下载 `*_x64-setup.exe`，以全机模式安装，系统可能要求管理员权限。
- macOS：Apple Silicon 使用 ARM64 DMG，Intel Mac 使用 x64 DMG。
- Linux x64：可运行 AppImage，或在 Debian/Ubuntu 上安装 deb。
- 现有 DSH Profile、模型配置、插件、缓存和凭据不会被迁移或重写。

### 已知限制

- Windows Authenticode、Apple Developer 签名与公证仍未配置。
- macOS 与 Linux 仍需在对应真实桌面环境完成最终交互验收。

## English

DSH Desktop `0.1.4` bundles DeepSeek Harness `{{DSH_VERSION}}` and focuses on runtime synchronization, startup stability, and Windows compatibility.

### What's changed

- Bundled DeepSeek Harness moves from `0.1.1-rc.2` to `{{DSH_VERSION}}`, with the complete DSH dependency tree and npm integrity metadata refreshed.
- Fixed HMR startup failures by enabling Node internal module access before the DSH entry on Windows and POSIX launch paths.
- Added a Windows WebView2 GPU compatibility configuration to improve rendering stability on affected devices.
- About, runtime verification, and diagnostic information now report the updated DSH version.
- Target Node binaries, native modules, SHA-256 hashes, supply-chain policy, and local Web service startup remain verified.

### Installation

- Windows x64: download `*_x64-setup.exe`; per-machine installation may require administrator rights.
- macOS: use the ARM64 DMG on Apple Silicon or the x64 DMG on Intel Macs.
- Linux x64: use the AppImage or install the deb package.
- Existing DSH profiles, model settings, plugins, caches, and credentials are not migrated or rewritten.

### Known limitations

- Windows Authenticode and Apple Developer signing/notarization remain unconfigured.
- Final macOS and Linux interaction acceptance still requires real desktop environments.
